# 页面变化发布为新的不可变 Feed 条目

信息流核心不再保存同一 Feed 条目的多个内容版本，处理结果直接绑定不可变的 Feed 条目。采集供给端可以保留最近一次页面观测快照和内容指纹用于变化比较，但每次确认页面变化都必须向物化 Feed 发布具有新 GUID 的页面变化消息，而不是修改既有条目。这个决定让核心与 FOLO 的 Entry 阅读模型保持一致，并将页面变化历史表达为普通时间线消息；代价是供给端必须生成稳定且不重复的变化事件身份，并负责过滤无意义抖动。该决定取代 ADR-0012，并修正 ADR-0023 中由核心负责内容版本的边界。
