# 将信息流核心与采集供给端拆为独立服务

Feeds Agent 在同一仓库中拆分为可独立部署的 `feed_core` 与 `feed_supplier` 服务，分别拥有独立 Python 包、依赖清单、配置、SQLite 和持久卷，运行时只通过内部 HTTP Feed 通信。核心只负责 Feed 订阅、不可变 Feed 条目、处理、存储和展示；所有非 Feed 平台访问、页面变化检测、清洗、凭据、调度与物化 Feed 发布属于供给端。拆分采用全新数据库和一次性强迁移，不保留旧 API、兼容包、双写或 `feeds_agent` 运行入口。该决定以暂时删除平台行为专用卡片、核心采集通路管理、来源清洗和来源自带处理信号等能力为代价，换取两个模块可以独立修改、部署和恢复，并取代 ADR-0018 的单服务部署方案。核心不再保存条目内容版本的后续决定见 ADR-0024。
