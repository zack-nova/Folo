# 发布自有数据源路由目录

阶段 5A.4 由 `feed-supplier` 持有路由目录的权威数据。目录记录展示元数据、RSSHub 路径模板、公开参数 schema
和秘密查询参数的凭据引用，不调用或镜像 FOLO 官方目录。仓库不预置会随上游版本变化的路由，部署者通过
独立管理 API 明确发布与当前自建 RSSHub 版本匹配的模板。

`ADMIN_TOKEN` 只用于目录增删改、凭据绑定和管理测试。核心使用独立内部令牌读取已启用的脱敏目录、渲染
逻辑地址和执行连接测试，再通过实例 Owner 会话向前端提供扩展 API。浏览器与核心都不能读取管理令牌；
浏览器也不能读取凭据 ID 或值。

目录参数只支持有界的 string、integer、boolean 和 enum。路径模板必须与 path 参数严格对应，query 参数
按 schema 白名单输出，秘密查询参数只在供给端解析后注入。目录拒绝点路径段和可匹配同一地址的歧义模板；
核心对公开响应使用严格 schema，不允许额外管理字段跨越内部信任边界。启用的目录模板参与
`managed_only` 解析，精确路由实例优先。最终仍保存标准 `rsshub://` 逻辑身份，并复用已有 FeedImporter、
订阅、Action 与 AI 流水线。
